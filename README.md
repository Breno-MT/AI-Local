# AI-Local
### This project is based on running an AI model locally, in search of performance and seek help with daily tasks, and anything that the model can help with, which can include researchs, code and few more things that the model offers.

# About the AI
### I'm using for this project the model [Qwen3VL-8B-Instruct-Q4_K_M.gguf](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct-GGUF).

# Requirements
### Python 3.15 and the .env configured as the .env_example
